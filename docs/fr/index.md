# Prises connectées qui suivent les prix Nord Pool

<p class="lead">Spot Price Plugs est une application Android gratuite qui trouve vos prises
Tasmota, OpenBeken et Shelly sur le réseau domestique et les allume pendant les heures les moins chères
de Nord Pool — chaque jour, automatiquement.</p>

## Comment ça marche

1. **Trouvez les prises** — l'application scanne votre réseau Wi-Fi et détecte les prises Tasmota, OpenBeken et Shelly.
2. **Choisissez les heures** — par exemple les 4 heures les moins chères par jour, TVA incluse, jamais au-dessus de votre plafond de prix.
3. **C'est tout** — chaque jour après la publication des prix Nord Pool (≈13:00 CET), le planning se met à jour tout seul.

## Prises prises en charge

Toute prise connectée avec le firmware **Tasmota**, **OpenBeken** ou **Shelly** fonctionne. Par exemple :

- [Nous A1T](https://nous.technology/product/a1t.html) — une prise Tasmota (UE, 16 A)
- [Shelly Plug M Gen3](https://www.shelly.com/products/shelly-plug-m-gen3-white) — une prise Shelly Gen3

À acheter sur le [site officiel Shelly](https://www.shelly.com/), la [boutique Nous](https://nous.technology/)
ou dans votre magasin d'électronique local.

## Économies typiques

Un chauffe-eau de 2 kW qui chauffe 4 kWh par jour coûte environ **€200–250/an** au prix moyen —
mais seulement **€75–110/an** s'il chauffe pendant les heures les moins chères. Une seule prise
se rembourse en quelques mois. Le calcul complet est dans le
[blog]({{ site.baseurl }}/fr/blog/save-on-water-heating/).

## Prérequis

- Android 8.0+, même réseau Wi-Fi que les prises
- Prise avec firmware Tasmota, OpenBeken ou Shelly (sans mot de passe sur l'interface web)
- Zone Nord Pool : LV, EE, LT, FI, SE1–4, DK1–2, NO1–5, PL, DE, AT, BE, NL, FR
