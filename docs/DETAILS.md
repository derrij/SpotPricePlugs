# Spot Price Plugs — подробное описание

[← назад к README](../README.ru.md) · [English version](DETAILS.en.md)

Нативное приложение вместо Python-скрипта: само находит розетки Tasmota и
Shelly в домашней сети, читает параметры из имени устройства, скачивает цены
Nord Pool и записывает таймеры/расписание. ПК, Termux, MQTT-брокер и облако
не нужны.

## Что внутри

| | |
|---|---|
| Язык / UI | Kotlin, Jetpack Compose (Material 3) |
| Минимальная версия | Android 8.0 (API 26) |
| Сборка | AGP 9.4.1, Gradle 9.6, compileSdk 37, targetSdk 36 |
| Сеть | HTTP к розетке в локальной сети, HTTPS к API Nord Pool |
| Фон | `AlarmManager` (точный будильник) + `WorkManager` (страховка) |
| Хранение | `SharedPreferences` (IP, настройки) + файловый кэш цен |

## Устройства

Поддержаны два семейства с открытым HTTP API:

| | Tasmota | Shelly |
|---|---|---|
| Определение при скане | `Status0` | `/rpc/Shelly.GetDeviceInfo` (Gen2/Gen3), затем `/shelly` (Gen1) |
| Реле, кнопки в карточке | `Power` | `Switch.Set` / `/relay/0?turn=` |
| Расписание | 16 таймеров `Timer N` | Gen2/3: по заданию `Schedule.Create` (cron `timespec`) на каждое переключение; Gen1: `/settings/relay/0?schedule_rules=` |
| Пауза плана | `Timers 0/1` | Gen2/3: `Schedule.Update enable=false/true`; Gen1: `/settings/relay/0?schedule=false/true` |
| Ваттметр | нет (мощность в имени) | есть (`apower`/`meters`) — берётся автоматически, если `W` в имени нет |

Название и параметры (регион, часы, мощность, лимит) считываются одинаково
у обоих семейств — из имени устройства (`name` в Shelly, `DeviceName`
в Tasmota). Бейдж под IP показывает, что за прошивка: `Tasmota`,
`Shelly Gen2/3 · SPLM-002PE01EU` и т.п.

**OpenBeken** (OpenBK7231T_App: розетки на BK7231, BL602 …) отвечает на тот же
`cm?cmnd=`, что и Tasmota, и распознаётся по версии прошивки в `Status0`.
Реле и часы работают как у Tasmota, но команд `Timer` у неё нет, поэтому
расписание пишется событиями часов (`addClockEvent HH:mm <дни> <id> POWER
ON|OFF`, id 7301–7316; собственные события пользователя не трогаются).
Ограничения:

* события часов хранятся в памяти розетки и пропадают при её перезагрузке,
  поэтому те же команды записываются и в `autoexec.bat` в файловой системе
  розетки (между строками `// spotpriceplugs begin` / `end`; остальные
  строки файла не трогаются) — прошивка выполняет его при запуске. Если
  файловой системы нет, приложение при ежечасной проверке замечает
  перезагрузку по времени работы розетки и записывает расписание заново;
* розетка живёт с фиксированным смещением от UTC и не переходит на летнее
  время. Перед записью расписания приложение ставит `ntp_timeZoneOfs` по
  текущему смещению телефона и добавляет ту же строку в свой блок
  `autoexec.bat` — она перекрывает смещение из команды запуска розетки.
  После перевода часов время на розетке расходится на час до следующего
  обновления, но уже записанные события срабатывают в нужные моменты;
* на розетке должен быть запущен драйвер NTP (`startDriver ntp` в команде
  запуска), иначе обновление остановится с ошибкой «часы розетки не
  установлены»;
* пауза плана удаляет события, возобновление записывает их снова.

Ограничения Shelly:

* до 20 заданий расписания на розетку (наш лимит — 8 блоков = 16 заданий);
* Gen2/3: приложение запоминает id своих заданий в KVS розетки
  (`spotpriceplugs_jobs`) и заменяет только их — ваши собственные расписания
  не трогает (если они оставляют слишком мало места, обновление остановится
  с сообщением);
* у Gen1 один список правил на реле, поэтому приложение полностью им
  владеет и перезаписывает при каждом обновлении;
* если у Shelly стоит пароль, приложение без логина не управляет ей —
  ввод пароля ещё не реализован;
* экономия в евро у Tasmota считается только по мощности из имени/карточки;
  у Shelly мощность дополнительно берётся из ваттметра прямо во время
  обновления и запоминается.

## Установка

1. Скачайте APK со страницы [Releases](https://github.com/derrij/SpotPricePlugs/releases/latest)
   и откройте его на телефоне (или `adb install`).
2. Разрешите установку из неизвестных источников для файлового менеджера.
3. Откройте приложение. Оно сразу попросит:
   * **Уведомления** — не обязательны, но с ними Android реже душит фон;
   * **Точные будильники** — кнопка «Будильники» (Android 13+ не выдаёт это
     разрешение автоматически);
   * **Батарея → Без ограничений** — кнопка «Батарея». На Xiaomi/Samsung
     дополнительно разрешите автозапуск в фирменных настройках.
   Статусы разрешений в приложении обновляются сразу после возврата из
   системных настроек — перезапускать его не нужно.
4. Телефон должен быть в той же Wi-Fi-сети, что и розетки.

## Первый запуск

1. Подсеть определяется автоматически (`192.168.1`, `10.85.228`, …). Если
   определилась не та — впишите вручную и нажмите «Авто» для повторного
   определения.
2. **Найти розетки** — приложение опрашивает 254 адреса подсети
   (Tasmota `Status0`, затем Shelly). Занимает 5–30 секунд.
3. Найденные розетки сохраняются. Для каждой видно имя, IP, регион, часы,
   лимит, мощность, время последнего и **следующего** обновления (оно может
   отличаться: зависит от того, на сколько суток хватило плана). Кнопка
   «Изменить» правит регион, часы, лимит и мощность именно этой розетки,
   «Пересчитать» пересчитывает только её, «Удалить розетку» убирает её из списка.
4. **Обновить всё** — скачивает цены, строит план и пишет таймеры.

## Карточка розетки

Каждая найденная розетка выглядит так:

* **кнопки «Включить / Выключить»** — прямое управление реле
  (`Power ON/OFF`), независимо от плана;
* **«Пауза плана» / «Продолжить»** — `Timers 0` и `Timers 1`: на паузе
  розетка перестаёт следовать расписанию, таймеры в ней просто отключены.
  Ежедневный пересчёт всё равно записывает в розетку на паузе свежие таймеры,
  но оставляет их выключенными, так что «Продолжить» всегда начинает со
  свежего плана;
* **график** — полоса цвета по цене каждого 15-минутного слота (синий —
  дёшево, красный — дорого), зелёные куски — запланированное включение,
  белая линия — текущий момент. Расписаны сегодня и завтра, подписано,
  на сколько часов хватает плана;
* **строка «Сейчас»**: текущая цена и время до ближайшего переключения —
  обратный отсчёт обновляется раз в 30 секунд;
* **«сэкономлено»** — накопленная оценка, см. раздел ниже.

## Экономия

| Где видно | Что означает |
|---|---|
| «дешевле на 19%» | средняя цена выбранных слотов ниже средней цены суток |
| «0.53 €» | экономия по плану в деньгах; появляется, когда известна мощность |
| «сэкономлено: сегодня X € · за 7 дней Y €» | сумма оценок за все загруженные планы |

Мощность приложение берёт из имени устройства (`1500W`, `2kW`) или из карточки
(«Изменить» → «Мощность, Вт»). Без мощности показываются только проценты —
честно посчитать евро нельзя, потому что неизвестно, сколько кВт·ч
потребляет нагрузка.

Формула: `(средняя цена суток − цена слота) × 0.25 ч × кВт` для каждого
выбранного слота. Для сегодняшнего дня считаются только будущие слоты, поэтому
оценка за «сегодня» ниже полной дневной. Ручное включение реле в дорогой час
в экономию не попадает — счётчик честно показывает только выгоду плана.

## Имя устройства

```
Boiler DE 4h 2000W max0.20
       │  │  │     └── максимальная цена, EUR/кВт·ч с НДС
       │  │  └──────── мощность нагрузки, Вт (для счётчика экономии)
       │  └─────────── сколько часов в сутки (можно 0.5h, 2.5h, 8h …)
       └────────────── зона Nord Pool: LV, EE, LT, FI, SE3, NO1 …
```

Порядок токенов любой, регистр не важен — кроме двухбуквенных зон (`LV`,
`DE`, `AT`, `BE`…): их нужно писать заглавными, чтобы обычные слова вроде
«at» или «be» не принимались за зону. Разделители — пробел, `_` или `-`.
Что распознаётся:

| Параметр | Варианты записи |
|---|---|
| Регион | `LV`, `EE`, `SE3`, `NO1` … отдельным словом |
| Часы | `4h`, `2.5h`, `4 hours`, `4ч`, `4_hours` |
| Мощность | `1500W`, `1500 watts`, `2kW`, `1.5kW` |
| Макс. цена | `max0.20`, `max 0.20`, `limit_0.20`, `threshold 0.20`, `<0.20`, `≤0.20` |

Старые имена вида `Scooter_LV_4_hours_1500W_on_limit_0.20` продолжают
работать. Запятая в числах тоже: `max0,20`.

Всё это необязательно. Если региона нет в имени, приложение берёт его из
настроек — поле **«Регион»** в блоке «Настройки» задаёт зону для всех розеток,
у которых регион не указан. Часы, цена и мощность без цифр в имени тоже
берутся из настроек.

Регион, часы и лимит можно поменять и в приложении, отдельно для каждой
розетки: «Изменить» → нужные поля → «Сохранить». Значения из `DeviceName`
подставляются при первом сканировании; дальше хранится то, что вы сохранили.
Регион для конкретной розетки важнее общего из настроек.

## Настройки

| Поле | По умолчанию | Что означает |
|---|---|---|
| НДС, % | пусто (авто) | прибавляется к биржевой цене; пусто — ставка страны по региону розетки (LV 21, EE 22, LT 21, FI 25.5, SE/DK/NO 25, PL 23, DE 19…), можно указать свою, в т.ч. 0 |
| Обновление | 14:05 | ежедневное время пересчёта (по часовому поясу телефона) |
| Часов в сутки | 4 | сколько часов в сутки включать новым розеткам |
| Макс. цена | 0.20 | максимальная цена, EUR/кВт·ч с НДС, для новых розеток |
| Регион | пусто | зона Nord Pool для розеток без региона в `DeviceName` |
| Мощность, Вт | не задана | мощность нагрузки для розеток без `W` в имени |

Часы, лимит, регион и мощность из этого блока — значения по умолчанию:
они применяются к розеткам, у которых этих данных нет в имени. Уже
сохранённые устройства хранят свои значения и правятся через «Изменить».

## Когда обновляется расписание

| Событие | Что происходит |
|---|---|
| Ежедневно в **14:05** по местному времени телефона | Биржа уже опубликовала цены на завтра → план продлевается на сутки |
| Конец последнего блока плана | План исчерпан → сразу строится новый |
| Цены на завтра ещё не вышли | Повтор через 15 минут (до 5 попыток), ночью не спамит |
| Перезагрузка телефона, смена времени/пояса, обновление APK | Будильники ставятся заново |
| Открытие приложения | Показывает состояние; обновление — по кнопке |
| Раз в 12 часов (при открытии или фоновом запуске) | Проверка новой версии на GitHub Releases; в фоне — уведомление |

Время 14:05, а не 13:00, потому что Nord Pool публикует результаты около
13:00 CET. В любом часовом поясе остаётся запас до публикации: приложение
считает сутки в часовом поясе телефона, а цены запрашивает по CET-датам,
поэтому переезд в другой регион ничего не ломает.

Точный будильник срабатывает даже в Doze. Если он почему-то пропущен,
WorkManager дождётся сети и выполнит задачу на 25 минут позже. Если телефон
ночью выключен, розетка продолжает работать по записанным таймерам — они
хранятся в её флеше.

## Как считается план

1. Цены: `dataportal-api.nordpoolgroup.com/api/DayAheadPrices`, шаг 15 минут,
   EUR/МВт·ч без НДС → `EUR/кВт·ч = цена / 1000 × (1 + НДС/100)`.
2. Ответ кэшируется в памяти и в `cacheDir`. Полностью опубликованные сутки
   не меняются и повторно не запрашиваются; ещё не опубликованные —
   запрашиваются снова через 5 минут. Если биржа недоступна, используются
   цены из кэша. Несколько розеток одного региона используют **один** запрос.
3. Окно — от текущего 15-минутного слота до конца следующих суток. Прошедшие
   слоты не участвуют: запуск в 21:45 планирует 21:45–24:00 и завтрашний день.
4. На каждые сутки выбираются самые дешёвые слоты, не дороже лимита, — ровно
   `hours × 4` штук по 15 минут.
5. Соседние слоты образуют блоки «включить/выключить». Блок через полночь
   остаётся одним. Не больше 8 блоков на всё окно (16 таймеров Tasmota); при
   двух днях каждому доступно 4, а завтрашнему — ещё и то, что не использовал
   сегодняшний. Если самые дешёвые слоты слишком разбросаны, выбирается самый
   дешёвый набор, который помещается: ровно заданное время и ни одного слота
   дороже лимита (если так нельзя — розетка включается на меньшее время).
6. Маски дней: `Days` у Tasmota — 7 символов **с воскресенья** (`SMTWTFS`).
   Сегодняшний план получает «все дни, кроме завтрашнего», завтрашний — только
   завтра. Блок через полночь: ON по маске дня начала, OFF — дня окончания.
   Если цены только на сегодня, план повторяется каждый день (запасной режим).
7. В конце записывается `Timers 1` и текущее состояние реле по плану.

## Сборка

Проще всего открыть корень репозитория в Android Studio и нажать Run.

Из командной строки (JDK 17+; Android SDK с platform 37 и build-tools 36):

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat assembleDebug
```

APK появится в `app\build\outputs\apk\debug\app-debug.apk`.

Важно: AGP 9 включает Kotlin «из коробки», поэтому плагин
`org.jetbrains.kotlin.android` **не подключается** — иначе сборка падает с
`Cannot add extension with name 'kotlin'`. Подключён только
`org.jetbrains.kotlin.plugin.compose`.

Релизная сборка (`assembleRelease`) подписывается ключом из `keystore.properties`
(`storeFile`, `storePassword`, `keyAlias`, `keyPassword`); если файла нет —
отладочным ключом.

## Ограничения

* **Только HTTP.** Tasmota S26 (ESP8266) не умеет HTTPS, поэтому приложение
  ходит по `http://IP` и в манифесте стоит `usesCleartextTraffic`. Это нормально
  внутри домашней сети; в чужом Wi-Fi розетки всё равно недоступны.
* **MQTT не поддерживается.** Приложение пишет таймеры напрямую по HTTP.
  Брокер нужен только если розетка в другой сети (VPN/роутер) — тогда
  используйте Python-версию.
* **Розетка должна быть в той же сети в момент обновления.** Если в 14:05
  телефон только на мобильном интернете, ничего не отправляется и ошибки не
  показываются; задача выполнится, как только телефон вернётся в Wi-Fi (до
  этого проверка раз в час). Таймеры в розетке продолжают работать по старому
  плану.
* **В фоне обновляются только те розетки, которым пора.** Плановый запуск
  берёт розетки, чьё время подошло, и пропускает розетку, у которой таймеры
  не изменились бы, — одна недоступная розетка не заставляет переписывать
  остальные. «Обновить всё» записывает всё всегда.
* **Розетки узнаются по MAC.** Если роутер раздал новые адреса, «Найти
  розетки» переносит настройки и экономию каждой розетки на её новый IP.
  Перед каждой записью приложение проверяет, что по сохранённому IP отвечает
  то же устройство.
* **Перевод часов.** Розетка, чьи часы совпадают с телефоном, считается
  живущей по тем же правилам летнего времени (Shelly; Tasmota с
  `Timezone 99`) — блоки после перевода остаются на своём месте. Tasmota с
  фиксированным `Timezone` получает время по своему фиксированному смещению.
* **Максимум 16 таймеров** = 8 блоков. Больше Tasmota не умеет.
* **Розетка должна знать время (NTP).** Перед записью таймеров приложение
  читает часы розетки (`Status 7` у Tasmota, `Sys.GetStatus` / `/status`
  у Shelly) и пишет время в её собственном часовом поясе, так что стандартный
  `Timezone 1` не мешает. Если часы ни разу не синхронизировались, обновление
  остановится с сообщением «часы розетки не установлены».
* **Смена расписания вручную.** Приложение перезаписывает все 16 таймеров при
  каждом обновлении, поэтому таймеры, созданные в веб-интерфейсе Tasmota,
  будут стёрты.
* **Обновление поверх старой версии** возможно, только если APK подписан тем же
  ключом. Релизы на GitHub подписаны одним ключом — ставьте их поверх смело.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| «Розетки не найдены» | Телефон в другой сети/VPN, розетка выключена, в роутере включена изоляция клиентов |
| «Укажите регион в приложении или в имени устройства» | Добавьте `LV` (или свой регион) отдельным словом в имя устройства либо укажите регион в настройках приложения |
| «Данные за … неполные» | Биржа ещё не отдала цены; подождите 14:05 или нажмите «Обновить всё» позже |
| «Nord Pool вернул HTTP …» | Нет интернета или API недоступен; повторите позже |
| «… не ответил на команду» | Розетка недоступна по этому IP (сменился DHCP) — просканируйте сеть заново |
| «По этому адресу отвечает другое устройство» | Роутер отдал IP розетки другому устройству — просканируйте сеть заново, розетка найдётся по MAC |
| Розетка в списке «Не управляется» | Она найдена без параметров в имени — нажмите «Управлять этой розеткой» |
| Обновления не приходят | Проверьте разрешения «Будильники» и «Батарея», автозапуск в настройках производителя |
| График в карточке пустой | Розетка ещё ни разу не пересчитывалась (или плана не было) — нажмите «Пересчитать» |
| «Сейчас ВКЛ», а розетка холодная | Реле переключали вручную либо план изменился; кнопка «Включить/Выключить» управляет реле сразу и не ждёт таймеров |
| Экономия в евро не показывается | Укажите мощность (Вт) в карточке или добавьте `1500W` в DeviceName |
| «Часы розетки не установлены» | У розетки нет интернета/NTP; проверьте `Time` в её консоли и NTP-серверы |
